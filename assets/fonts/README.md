# Fonts

`DejaVuSans.ttf`, `DejaVuSans-Bold.ttf` and `DejaVuSansMono-Bold.ttf` are bundled so every
frame renders identically on any host (no system font hunting, no `apt-get`).

DejaVu fonts are released under the Bitstream Vera / DejaVu license, which allows free
redistribution and embedding. See https://dejavu-fonts.github.io/License.html
